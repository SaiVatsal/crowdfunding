# Project 54: Crowdfunding Platform (IgniteLaunch)

A decentralized community crowdfunding and creative project backer platform built with **React 18 + Vite 5 + Tailwind CSS 3.4 + Zustand 4.5**.

## Features
- **Campaign Discovery & Filtering**: Live category browsing across Tech & Hardware, Games, Eco Innovations, and Publishing.
- **Interactive Perks & Reward Tiers**: Early Bird packages, Collector's kits, and custom tip contributions.
- **Real-Time Funding Progress**: Animated progress bars, percentage indicators, backer count, and days remaining.
- **Creator Studio & Payout Desk**: Automated 5% platform fee deduction, net disbursable funds, and backer shipping fulfillment tracker.
- **Backer Update Feed & Likes**: Community milestone announcements and transparent production updates.
